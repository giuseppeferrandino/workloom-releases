# Workloom — app desktop

Qui vengono pubblicati solo gli installer dell'app desktop di Workloom (macOS e Windows) e gli aggiornamenti automatici.
Il codice sta in un repository privato. Per usare l'app serve un account sul server Workloom.

## Installazione

Scarica l'ultima versione da **[Releases](../../releases/latest)**.

L'app per ora non è firmata con un certificato, quindi il sistema mostra un avviso al primo avvio:

- **Windows** — "Windows ha protetto il PC": clicca **Ulteriori informazioni → Esegui comunque**.
  Gli aggiornamenti successivi arrivano da soli.
- **macOS** — apri il file `.dmg`, trascina Workloom in Applicazioni, poi la prima volta **tasto destro sull'app → Apri → Apri**
  (oppure Impostazioni di Sistema → Privacy e sicurezza → Apri comunque).
  Quando esce una nuova versione l'app te lo segnala con il link per scaricarla.
